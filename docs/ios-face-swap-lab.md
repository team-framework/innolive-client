# iOS 실험실 비식별화 방법

대상은 앱 정보 및 계정 화면의 실험실 섹션이다. 화면을 열 때 `GET /admin/me`를
보내 200이면 실험실 섹션을 표시한다. 403·404·네트워크 실패는 관리자가 아닌 것으로
보고 숨긴다.

실험실에는 비식별화 방법 하나만 둔다. 선택지는 블러·합성·토끼·부엉이이고 기본값은 블러다.
토끼·부엉이는 온디바이스 처리에서만 쓰고 서버 요청에는 보내지 않는다([on-device-animal-assets.md](on-device-animal-assets.md)).
선택값은 `com.framework.innolive.face-anonymization-mode`에 저장한다. 합성을 고르면
서버 AI 세션 생성 요청(`POST /sessions`)에 `face_anonymization: "face_swap"`을 보낸다.
블러는 서버 기본값이라 필드를 생략한다. 온디바이스 처리(서버 송출 포함)에서는 보내지
않는다. 서버가 `on_device` + `face_swap`을 400으로 거절하기 때문이다.

모드는 세션 생성 때 고정된다. 방송 준비 중(세션이 있을 때)에는 선택을 막고, 다음
방송 준비부터 적용한다.

## 검증

`FaceAnonymizationLabTests`에서 기본값 블러, 처리 방식별 요청 본문,
`/admin/me` 200·403·404 판정, 합성 세션 생성 요청 본문을 검사한다.

실기기 확인 절차:
1. 관리자 계정으로 로그인해 앱 정보 및 계정 화면에 실험실 섹션이 보이는지 확인한다.
2. 비관리자 계정에서 실험실 섹션이 보이지 않는지 확인한다.
3. 합성을 고르고 서버 AI로 방송을 준비해 미리보기와 송출 화면의 얼굴이 합성되는지 확인한다.
