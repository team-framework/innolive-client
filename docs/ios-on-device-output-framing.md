# iOS 온디바이스 출력 화각

- 카메라 원본 1배 영상을 YOLO 입력, GMC, BoT-SORT, YuNet·AdaFace 및 마스크 합성에 사용한다.
- 가림 처리를 합성한 최종 영상만 중심 기준 1.1배 확대하고 원래 출력 크기로 자른다.
  각 축에서 중앙 1/1.1(약 90.91%)을 사용하므로 원본 가장자리 약 4.55%씩 제외한다.
- `PrivacyModel`의 공통 출력에서 적용하여 CGImage 미리보기와 CVPixelBuffer 미리보기·송출이 같은 화각을 사용한다.
  송출은 확대 후 센서 방향으로 복원하며 기존 회전 메타데이터와 해상도를 유지한다.
- 서버 AI 입력·출력, 원본 얼굴 등록 이미지, 카메라의 물리적 zoom 설정과 HTTP/WebRTC 계약은 변경하지 않는다.
- `PrivacyOutputFramingTests`는 가로·세로 720p/FHD 크기, 4방향 회전, 모서리 제거와 마스크 동시 확대를 검증한다.
  실제 카메라 탐지 정확도 및 외부 방송 송출 품질은 실기기 검수가 필요하다.

검증: 2026-10-21 iOS 26.5 시뮬레이터에서 `PrivacyOutputFramingTests` 3개 통과.
승인·추적·마스크·uplink를 포함한 관련 테스트 총 48개 통과, 실패·skip 없음.
