# iOS 계정 정보 수집·이용 동의

대상은 iOS 이메일 회원가입과 Google·Apple 로그인입니다. 기존 소셜 사용자도 로그인할 때 확인합니다. 기존 이메일 로그인과 저장된 로그인 복원에는 추가 동의를 요구하지 않습니다.

로그아웃 첫 화면에는 Google·Apple·이메일 진입 버튼만 표시합니다. 개인정보처리방침은 가입·OAuth 진행 전 동의 모달 안의 전문 링크로만 엽니다.

## 문구 기준

2026년 9월 10일 시행 개인정보처리방침의 계정 정보 수집 항목, 목적, 보유·삭제 기준과 외부 로그인 설명을 요약합니다.

앱 언어에 맞는 요약과 전문 링크를 제공합니다. 보관 기간, 학습 이용 여부 등 방침에 없는 약속을 추가하지 않습니다. 미동의 시 가입·소셜 로그인을 진행하지 않는 것은 이번 앱 흐름의 조건입니다.

## 화면과 진행 조건

공통 동의 모달은 스크롤 완료 상태와 동의 완료 상태를 분리합니다. 본문 끝까지 스크롤하면 `동의하고 계속`을 활성화합니다. 본문 전체가 한 화면에 들어오면 바로 활성화합니다. 위로 다시 스크롤해도 활성화 상태를 유지합니다. 버튼을 누르기 전에는 동의하지 않습니다. 취소 버튼 또는 시트 닫기로 종료하면 가입 요청·소셜 인증을 실행하지 않습니다. 새 시트는 스크롤·동의 상태를 초기화합니다.

1. Google·Apple 로그인 버튼을 누르면 공통 동의 시트를 엽니다. 본문을 끝까지 읽고 `동의하고 계속`을 누른 뒤에만 해당 OAuth를 시작합니다.
2. 이메일 가입은 계정 만들기 화면에서 이메일·비밀번호·비밀번호 확인을 입력한 뒤 제출하면 같은 동의 시트를 엽니다. 동의하면 시트를 닫고 입력 화면으로 돌아옵니다.
3. 계정 만들기 화면의 제출 버튼 위에 동의 체크박스를 표시합니다. 모달 동의 후 체크박스를 선택 상태로 표시합니다. 체크박스가 선택된 상태에서만 계정 생성 요청을 실행합니다.
4. 본문에는 수집 항목, 이용 목적, 보유·삭제 기준, 외부 로그인 설명, 문의·철회 안내와 개인정보처리방침 전문 링크를 표시합니다.

`동의하고 계속`은 본문 아래 고정 영역에 배치합니다. 스크롤 완료나 전문 링크 열람만으로 동의하지 않습니다.

## 동의 상태 수명

- 이메일 가입 화면은 동의 체크 상태를 보유합니다. 같은 가입 흐름의 요청 재시도와 코드 재전송에는 동의를 유지합니다.
- 이메일 가입 취소, 로그인·가입 화면 전환, 가입 화면을 떠나는 경우에는 동의 상태를 초기화합니다.
- 소셜 인증 취소·실패 후 다시 로그인 버튼을 누르면 새 동의를 받습니다.
- 동의 상태는 메모리에만 둡니다. 인증 흐름 종료와 앱 재실행 후에는 재사용하지 않습니다.
- 서버 API, HTTP·signaling payload와 토큰 저장 방식은 변경하지 않습니다. 서버 동의 이력과 영구 저장은 이번 범위에 포함하지 않습니다.

## 검증

- 단위 테스트: 스크롤 전 동의 차단, 끝까지 읽은 뒤 명시적 동의, 짧은 본문, 새 시트 상태, 미동의 가입 요청 차단, Google 요청 차단, 이메일 체크 해제 차단, 이메일 재시도·재전송·취소, 기존 이메일 로그인.
- 화면 확인: 로그아웃 첫 화면에 개인정보처리방침 버튼이 없는지, 한국어·영어·일본어, 라이트·다크 모드, 큰 글씨, VoiceOver로 끝까지 이동, 취소·재진입, 연속 탭.
- 실제 인증 확인: 동의 전 이메일 요청과 제공자 인증이 시작되지 않는지, 동의 후 이메일 인증 및 Google·Apple 로그인이 완료되는지 확인합니다.
- 빌드와 단위 테스트는 실제 제공자 인증이나 VoiceOver 화면 동작을 입증하지 않습니다.

- ko/en/ja 번역 330개와 컴파일러가 추출한 문구 328개를 검사했습니다.
- 실제 이메일·Google·Apple 인증, 스크롤 후 동의와 취소·재진입, 세 언어 화면, 큰 글씨·VoiceOver 동작은 사용자 빌드 테스트에서 확인해야 합니다.
- 기존 카메라 코드의 actor 격리 경고는 이번 변경 범위 밖으로 남겼습니다.

## 후속 범위

카메라·마이크 연결 직전 서버 전송 별도 동의와 YouTube 미디어 전송 직전 안내는 후속 작업입니다. 이번 변경으로 해당 기능을 구현한 것으로 보지 않습니다.
