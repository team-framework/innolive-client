# Android 1.4.0 패치노트

- 버전: 1.4.0 (versionCode 8)
- 작성일: 2026-10-20
- 이전 버전: 1.3.0 (versionCode 7)

## 새로운 기능

- 방송의 가림 처리 전·후 영상과 음성을 기기에 저장하는 녹화 기능과 저장된 방송 보관함을 추가했습니다. MP4 공유, 영상·음성 분리 공유, 갤러리 저장을 지원합니다.
- 방송 화면에서 얼굴을 눌러 이름과 함께 등록하는 원탭 얼굴 등록을 추가했습니다.
- YouTube 시청자 채팅을 방송 화면 위에서 확인하고 숨기거나 다시 표시할 수 있습니다.
- 플랫폼을 연결하지 않고도 온디바이스 비식별화 미리보기를 사용할 수 있습니다.
- 관리자 계정의 실험실에 서버 AI 비식별화 방법 선택을 추가했습니다. 얼굴 합성은 서버에서 허용한 경우에 사용할 수 있습니다.

## 화면과 사용성 개선

- 방송 화면을 카메라·기본·설정 페이지로 나누고 좌우로 이동할 수 있도록 구성했습니다.
- 작은 미리보기 창을 원하는 위치로 옮길 수 있게 하고, 가로 화면과 작은 화면의 버튼 배치를 개선했습니다.
- 방송 상태와 사용량 표시, 설정 화면, 요금제 안내와 팝업의 가독성을 개선했습니다.
- 온디바이스 블러와 얼굴 보호 여백을 개선했습니다.

## 안정성 개선

- 사용량 안내 배너가 사라질 때 앱이 종료되는 문제를 수정했습니다.
- release 빌드에서 AI 처리에 필요한 네이티브 연결 코드가 제거되지 않도록 검증을 추가했습니다.
- 네트워크 혼잡 시 서버 영상 송신 비트레이트 조정을 개선했습니다.
- 가림 처리 실패 안내와 녹화 저장·중단 복구 처리를 보강했습니다.

## Google Play 업데이트 안내

방송 녹화와 보관함을 추가했습니다. 가림 처리 전·후 영상과 음성을 저장하고 공유할 수 있습니다.
얼굴 원탭 등록, YouTube 채팅 오버레이, 플랫폼 연결 없는 온디바이스 미리보기를 지원합니다.
방송 화면의 페이지 이동과 작은 미리보기 창 이동을 추가하고 가로 화면·설정 화면의 사용성을 개선했습니다.
사용량 알림 종료 오류와 AI 처리·영상 송신·녹화 저장의 안정성을 개선했습니다.
