# 랜딩 요금제 표시

2026-10-02 기준. 대상은 `apps/landing`의 가격 안내이며 결제·서버 요금제 계약을 변경하지 않는다.

| 플랜 | 정가 / 월 | 베타 / 월 | 월 방송 시간 | 1회 최대 시간 |
| --- | --- | --- | --- | --- |
| Spark | 0원 | 0원 | 5시간 | 2시간 |
| Glow | 9,900원 | 0원 | 무제한 | 무제한 |
| Beam | 19,900원 | 0원 | 120시간 | 8시간 |
| Plasma | 39,000원 | 0원 | 240시간 | 12시간 |

서버 플랜의 월 시간은 720p 단독 송출 기준이다. FHD 단독·720p 동시 송출은 2배, FHD 동시 송출은 3배 차감한다. Beam·Plasma 카드에는 월 방송 시간, 최대 FHD 화질, 두 플랫폼 동시 송출을 별도 항목으로 표시한다. Beam의 동시 송출은 720p, Plasma는 FHD까지 지원한다고 안내한다. 해당 항목에 별표를 붙이고 카드 아래에서 송출 방식별 차감 배수를 설명한다. Spark는 720p 단독만, Glow는 온디바이스 단독 송출을 안내한다. 1회 한도는 실제 방송 시간이다.

Crew 가격은 BM에서 재계산 대상으로 남아 있다. 임의 금액을 표시하지 않고 가격 문의로 연결한다. Business도 맞춤 견적이며, 두 플랜의 방송 시간은 도입 문의로 확인한다.

모든 개인·비즈니스 플랜은 각 언어의 `messages/<locale>.json`에서 해당 플랜에 `footnotes` 문자열 배열을 추가하면 카드 하단에 주의사항을 표시한다. 항목이 없거나 빈 배열이면 표시하지 않는다. `helpLabel`에 연결된 물음표 버튼은 Glow 온디바이스 설명 전용이며, 다른 플랜의 주의사항 표시는 이 버튼과 독립적이다.
