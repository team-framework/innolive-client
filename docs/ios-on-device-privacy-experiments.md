# 온디바이스 비식별화 실험 기록

기준 기기: iPhone 16, iOS 27. 작업 브랜치 `feat/ios-on-device-privacy/#281`.

## 2026-09-21 · 첫 로컬 비식별화 테스트

YOLO26n-seg를 FP16 Core ML로 변환하고, 카메라 → 탐지 → mask 복원 → 픽셀화·Gaussian blur → 미리보기를 연결했다.
모델 입력 640, 카메라 1080p/30 FPS, confidence 0.25, Core ML `.cpuAndNeuralEngine`을 사용했다.
로그인·서버 연결·송출은 제외했고 `InnoLive Local`을 별도 식별자로 설치했다.

서명된 기기 빌드와 설치·실행에 성공했다. 사용자가 약 90ms / 10 FPS를 보고했다.
이 시점에는 구간별 프로파일링을 추가하지 않았으므로 어느 처리 단계가 병목인지는 확인하지 않았다.
마스크 복원 테스트 4개가 통과했다. 재현 절차는 [실행 안내](ios-on-device-privacy-lab.md)를 참고한다.

이 커밋은 대화 중 실제로 실행한 첫 버전의 코드를 이후에 분리해 기록한 것이다.
커밋 생성 시각을 최초 실행 시각으로 해석하지 않는다.
