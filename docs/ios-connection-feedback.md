# iOS 서버 연결 피드백

로그인 후 홈 화면에 진입하면 기존 흐름대로 서버 세션과 카메라 업링크를 연결한다. HTTP와 WebRTC 계약은 변경하지 않는다.

- 연결 진행 상태는 하단 `서버 연결 중` 버튼에 표시한다. 중앙 로딩 박스, 영상 대기 안내와 별도의 하단 진행 배너는 표시하지 않는다.
- 서버 영상이 도착하면 기존 원격 영상 영역에 표시한다. 로컬 미리보기와 연결 재시도 버튼은 유지한다.
- 홈 오류 배너는 연결 또는 복구가 끝난 뒤 `YouTubeIntegration.errorMessage`에 확정된 오류를 한 번 표시한다. 업링크의 임시 오류를 먼저 표시하지 않는다.
- 홈 화면은 업링크 상태 publisher를 직접 구독해 연결 실패 시 복구를 실행한다.
- 방송 설정 시트가 열려 있으면 시트 안에서 오류를 표시하고 홈 배너는 숨긴다. 오류를 닫으면 기존 공통 오류 초기화 경로로 상태를 지운다.

## 확인

`BroadcastFeedbackTests`는 연결 진행 중 배너 생략, 업링크 실패와 복구 후 오류 표시, 닫기 후 상태 초기화, 재시도 실패의 새 오류 표시를 확인한다.

수동 확인 시 로그인 직후 연결 중 화면에 중앙 박스가 없는지, 서버 연결 실패 시 오류 배너가 하나만 나타나는지, 방송 설정 시트 안에서 오류를 닫으면 홈으로 돌아와도 사라져 있는지 확인한다.

2026-09-12 검증 결과:

- iOS 26.5 시뮬레이터 Debug 빌드와 테스트 87개 통과.
- ko/en/ja 번역 항목 315개, 형식 인수와 권한 문구 검사 통과.
- 저장된 로그인으로 앱 실행 후 활성 세션 오류 배너가 하나만 나타나는 것을 확인. 닫기 후 배너가 사라지고, 재시도 중 하단 연결 버튼만 로딩을 표시하는 것을 확인.
- 재시도 후 서버 연결을 완료하고 `방송 준비` 버튼으로 전환되는 것을 확인.
- 새 로그인 입력 과정, 실기기, 방송 설정 시트에서 오류 발생·닫기, YouTube 실제 송출은 수동 검증하지 않음.
