## 콘텐츠 검토 범위와 예외

- 가이드 33개는 고유 title/description·서버 HTML·직답·FAQ·관련 링크를 자동 검사한다. 한국어 소개 가이드의 배경 도입은 직답으로 바꾸고 영어·일본어도 맞췄다.
- 제목 50~60자·설명 150~160자 지침은 영어 중심 권고로 취급한다. 한국어·일본어를 길이만 맞추려고 늘이지 않는다.
- 기존 blog는 언어별 2편이다. 빈약한 목록 페이지나 새 외부 블로그를 만들지 않고 기존 URL과 RSS를 사용한다.
- 외부 크로스포스팅은 원본 색인이 확인된 뒤 진행한다. 이번에 새로 만든 소개 페이지는 색인 확인 전이며, 개인 네이버 블로그를 팀 공식 채널로 임의 지정하지 않는다.
- `/ko/obs-face-blur`는 이전 지원 범위 정리로 제거된 URL이다. GSC의 404를 없애려고 미지원 OBS 기능을 다시 게시하지 않는다.
- 경쟁 서비스 기능표는 공식 설명 비교이며 성능 비교가 아니다. 원본 비교표의 2026-10-17 확인일을 유지한다.
