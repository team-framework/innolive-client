# iOS 플랫폼별 방송 설정

방송 설정 화면에서 YouTube·치지직을 선택하고 각 폼을 편집한다.
YouTube는 제목·설명·공개 범위·시청자층·카테고리,
치지직은 제목·카테고리 검색·태그를 제공한다.
방송 준비는 선택한 대상의 설정 저장 성공 후에만 진행한다.
카테고리·직전 값 조회에 실패해도 직접 입력할 수 있다.

HTTP payload, defaults 우선순위와 로컬 저장 경계는
[플랫폼별 방송 설정 계약](../contracts/api/broadcast-settings-v1.md)을 따른다.

치지직 연결은 서버 계정 목록으로 확인한다. 현재 iOS 계정 연결 화면의 치지직 OAuth는
별도 P1 작업으로 남아 있다. 이미 서버에 연결된 계정의 설정·준비 경로를 제공한다.
동시 송출 선택, 요금제, 방송 방식 전환과 업그레이드 화면은 이 변경에 포함하지 않는다.

## 검증

`BroadcastSettingsTests`에서 payload, provider와 owner header,
플랫폼별 초안·사용자·채널 분리, 직전 값 해제, 늦은 defaults·검색 응답,
누락·실패 defaults, 필드 오류, 저장 실패 시 prepare 차단을 확인한다.
기존 모델·Preferences·방송 회전 잠금·계정 API 테스트도 함께 실행한다.

Debug의 `--broadcast-settings-preview` 인자로 로그인·서버 요청 없이 폼을 열어
플랫폼 전환과 입력 오류를 확인한다. 실제 송출 증거로 사용하지 않는다.

빌드·테스트·화면 확인의 최종 결과는 PR 검증 기록에 남긴다.
실제 치지직·YouTube 계정의 영상·오디오 수신 검증은 별도 수행한다.

### 2026-09-30 결과

- iPhone 16 / iOS 27 시뮬레이터 Debug 빌드 성공, 설치·실행 확인.
- 집중 XCTest 64개 통과, 실패 0개. 신규 방송 설정 15개, 기존 모델·Preferences·회전·계정 API 36개, main의 요금제 13개.
- YouTube·치지직 폼 전환, 플랫폼별 제목 초안 분리, 빈 검색어 안내,
  YouTube 공개 범위·시청자층·카테고리 라벨, 제목 누락 필드 오류를 화면에서 확인.
- 한국어·영어·일본어 catalog 445개 항목의 번역·포맷 검증 통과.
  컴파일러 추출과 대조하면 기존 코드의 catalog 누락 23개가 남는다.
  이번 새 폼·편집기·모델에서 사용한 localized key 누락은 0개다.
- HTTP 계약은 additive이며 WebRTC signaling 변경은 없다.
- 실제 계정의 설정 저장·송출 영상·오디오 수신, 물리 기기 검증은 수행하지 않았다.

main의 요금제 변경을 병합해 방송 설정의 요금제 표시·준비 제한·계정 전환 시 초기화를 유지했다.
