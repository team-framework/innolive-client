# iOS 모자이크 강도·영역 조절

`영상 조절` 패널의 색감 조절 아래에 `모자이크` 영역이 있다. 서버 AI 처리 세션에서
두 슬라이더로 얼굴·번호판 블러를 바꾼다.

- 블러 강도: `blur_radius` 1~64, 기본 24
- 가림 영역 너비: `mask_margin` 0~64px, 기본 8px
- 모자이크 기본값: 두 값을 비워 서버 기본값으로 되돌린다

슬라이더에서 손을 떼면 앱이 `PUT /sessions/{id}/mosaic-config`를 보낸다.
VoiceOver처럼 드래그 없이 값을 바꾸면 바로 보낸다. 요청 중에 값을 또 바꾸면 마지막
값만 이어서 보낸다. 화면은 응답의 `media.mosaic_config` 확정값을 보여 주고, 실패하면
확정값으로 돌아가 패널 안에 오류를 표시한다.

색감 설정과 달리 모자이크 값은 서버 세션에 저장한다. 새 세션은 서버 기본값으로
시작하고, 앱은 값을 기기에 남기지 않는다.

세션이 없거나 온디바이스 처리 세션이면 조절을 막고 안내 문구를 표시한다.
온디바이스 가림 처리의 강도는 이 기능 범위 밖이다. 비식별화가 꺼져 있으면
설정은 바뀌지만 송출 영상에는 보이지 않으므로 안내 문구를 표시한다.
요청 중에는 AI 처리 위치 변경과 계정 작업을 막는다.

계약: [mosaic-config-v1](../contracts/api/mosaic-config-v1.md).

## 검증

`BroadcastSessionLifecycleTests`에서 픽스처 디코딩, 인증 헤더·경로·본문,
`pixel_size` 유지와 범위 보정, 기본값 요청의 빈 본문, 실패·필드 누락 시 확정값 유지,
요청 중 마지막 값 전송, 초기화 이후 응답 무시, 온디바이스 비활성화를 검사한다.

실기기 확인 절차:
1. 서버 AI 처리로 방송을 준비하고 비식별화를 켠 채 송출한다.
2. `영상 조절`에서 블러 강도를 1과 64로 바꿔 수신 화면의 얼굴 블러 차이를 확인한다.
3. 가림 영역 너비를 0과 64로 바꿔 가림 범위 차이를 확인한다.
4. 조절하는 동안 송출이 끊기지 않는지 확인한다.
5. `모자이크 기본값`으로 24·8px로 돌아오는지 확인한다.
6. 온디바이스 처리와 방송 준비 전 상태에서 슬라이더 비활성화를 확인한다.

자동 테스트와 빌드는 서버 배포 상태나 실제 송출 영상 검증을 대체하지 않는다.
