# Android 요금제와 방송 시간

Android는 기존 `GET /users/me/plan`과 `GET /users/me/usage`를 함께 읽는다.
[요금제 계약](../contracts/api/plan-usage-v1.md)과
[Notion Android 가이드](https://www.notion.so/3ebba097c65980b1a366f0126a55c626)의
2-4를 따른다. 요청·signaling 계약과 송출 방식은 변경하지 않는다.

홈과 설정 진입 및 방송 종료 때 조회하고 설정의 ‘요금제 및 사용량’에서
새로고침할 수 있다. 방송 중 설정은 15초마다 사용량을 다시 조회한다.
조회 사이에는 monotonic 시계와 현재 방식의 서버 차감 배수로 월 사용량·잔여량,
네 방식별 가능 시간을 초마다 계산한다. 일시정지는 차감을 멈추고 재개 때
이어지며, 조회 성공 때 계산 기준을 새 서버 값으로 교체한다. 계정 변경은
누적 차감 시계도 초기화한다. 이 계산은 표시용이며 과금은 서버가 결정한다.
방송 중 홈은 기존 세션 폴링을 사용한다.
현재 요금제, 월 한도, 1회 한도, 월 차감·잔여 시간과 네 방식별 월 방송 가능
시간·차감 배수를 표시한다. 허용 여부는 `allowed_modes`와 방식별 `allowed`를
모두 확인한다. 누락되거나 잠긴 방식은 잠금 표시를 누르면 안내가 열린다.
이 화면은 조회용이며 방식 전환 요청을 보내지 않는다.

방송 화면 오른쪽에는 흰색 업타임과 회색 남은 시간을 12dp 간격·20sp로
표시한다. [Figma](https://www.figma.com/design/YMdKyoB4jL5pD1yW1P0tzp/InnoLive?node-id=1673-2710)의
`00:00:00`과 `12min`을 기준으로 한다. 남은 시간을 누르면 설정을 연다.
분은 정수 부분을 표시하고 1분 미만은 초로 표시한다. 업타임은 기존 monotonic
시계를 유지하며 일시정지·재개 중에도 이어진다.

방송 전에는 서버 해상도와 활성 대상 수로 방식을 판단하고, 해당 방식의 월
가능 시간과 1회 한도 중 짧은 값을 표시한다. 조회되지 않았거나 잠긴 방식은
`—`로 표시한다. 방송 중에는 월 잔여량 대신 세션의
`broadcast_remaining_seconds`를 표시한다. 기존 2초 폴링으로 서버의 약
15초 갱신을 반영한다. 준비 단계의 null 또는 아직 없는 시간은 제한 요금제의
월 가능 시간과 1회 한도로 보완한다. 시간 숫자가 확인되면 세션 값이 우선한다.
월·1회 한도가 모두 무제한이고 세션 null이 확인된 경우에만 방송 중
무제한을 표시한다.

요금제 한도 0과 시간 필드 null은 무제한이며 사용량 0은 소진이다. 필수
필드 누락·음수·잘못된 배수·두 응답의 요금제 불일치는 조회 실패로 처리한다.
요금제 조회 실패는 마지막 완전한 값을 유지하고 오류·새로고침을 표시한다.
세션 조회 실패는 마지막 시간과 ‘마지막 조회값 · 재시도 중’을 표시한다.
확인된 시간 응답을 다시 받으면 이 표시를 해제한다.

기존 Bearer API 클라이언트와 401 갱신·1회 재시도를 재사용한다. 갱신 실패나
재시도 후 401은 로그인으로 돌아간다. 요금제 조회에는 owner token을 보내지
않는다. 캐시는 서버·JWT 사용자별로 분리하고 로그아웃·계정 변경 때 초기화한다.
화면·계정 변경으로 취소된 조회는 응답을 게시하지 않는다. 플랜 제한과 월
소진 서버 오류의 ‘요금제 및 사용량’ 버튼도 설정으로 연결된다.

검증은 `PlanUsageTest`, `PlanUsageApiTest`, `PlanUsageScreenTest`, 기존
`BroadcastApiFlowTest`와 설정 회귀 테스트로 수행한다. API 테스트는 HTTP
응답을 주입하며 실제 외부 방송·프로덕션 차감·물리 기기 검증과 구분한다.

2026-10-01 검증: 단위 테스트 254개, Pixel_10 / Android 17 집중 테스트
36개 통과. Debug APK와 instrumentation APK의 정상 native 포함 빌드 통과.
시간 표시·요금제 정상/실패 화면 캡처 확인. 프로덕션 요금제 조회·실제 송출
시간 차감·물리 기기 검증은 수행하지 않았다.

255개 통과. API·화면 테스트 9개 중 기존 캡처 1개의 PixelCopy 시간 초과가

교체 UI 테스트 통과. Debug 앱·instrumentation APK 빌드 통과.
