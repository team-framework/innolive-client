# 외부 채널 게시용 초안

상태: 외부 게시 보류. 사용자 결정에 따라 새 블로그를 만들지 않고 기존 `/ko/blog/live-face-blur`에 점검 장면과 웹 체험·실제 송출 구분을 보강했다. 아래 내용은 참고용 초안이다. 팀 공식 채널과 게시자를 확인한 뒤 사용한다. 원문은 네이버 검색·AI 브리핑에서 2026-10-19 실제 인용을 확인했다. 이 파일의 작성자를 개인 저자로 표시하지 않는다. 게시자가 사실을 검토한 뒤 본인 또는 팀 명의로 게시한다.

## 제목

라이브 방송에서 행인 얼굴을 가릴 때 확인할 것

## 본문

야외 라이브 방송에서 행인 얼굴을 가리려면 카메라 영상이 송출되기 전에 얼굴 감지와 블러 처리를 적용해야 합니다. 녹화 파일을 편집하는 기능과 라이브 송출 기능은 사용 시점이 다릅니다.

Framework 팀의 InnoLive에서는 방송에 공개할 사람의 얼굴을 먼저 등록합니다. 등록한 출연자의 얼굴은 보여 주고, 미등록 얼굴은 실시간 블러로 가린 뒤 유튜브·치지직으로 송출하는 방식입니다.

방송 전에 다음 장면을 확인하세요.

1. 출연자와 행인이 같은 화면에 들어오는 장면
2. 사람이 고개를 돌리거나 다른 사람에게 가려지는 장면
3. 얼굴이 작게 보이거나 조명이 어두운 장면

얼굴 크기·각도·가림·조명에 따라 감지 결과가 달라질 수 있습니다. 미리보기뿐 아니라 실제 송출 결과도 확인해야 합니다. 얼굴 처리만으로 이름표나 차량 번호판 등 다른 정보까지 가려졌다고 판단하면 안 됩니다.

InnoLive의 웹 체험에서는 카메라로 얼굴 감지와 블러 결과를 확인할 수 있습니다. 실제 방송은 방송 앱에서 준비합니다.

자세한 설명과 사용 범위는 공식 안내에서 확인할 수 있습니다.
