# iOS YouTube channel selection

The app keeps a single YouTube connection. The platform settings screen lists the connected channel with a disconnect confirmation. "Switch channel" invokes Google authorization with the previous SDK session signed out so the user can choose another account; after the account list confirms the new channel, every other YouTube connection is removed by its account ID. A failed removal keeps the new channel selected, leaves the remaining channel listed and reports the error. The app access token is unchanged. Android applies the same removal after connecting.

Broadcast settings shows the channel picker before preparing YouTube or adding YouTube during CHZZK broadcasting. When multiple channels are connected, each preparation/addition asks the user to confirm the selected channel name. Selection updates the settings scope and reloads defaults. Saving succeeds before prepare receives the selected account ID. A prepared/live YouTube target locks channel selection; the target title displays the server channel_title. Connecting a channel preserves the selected connection until the account list confirms both its channel and connection ID. The picker remains for accounts that still hold several connections from earlier versions. A failed list refresh keeps the previous selection and persisted connection. Refresh preserves the selected connection while it exists. Removing another channel preserves it.

Verification: focused URLProtocol tests cover account-specific DELETE, prepare/mode payloads, refresh/selection, and late defaults from a previous channel. Actual Google/brand-channel consent and production two-channel streaming require account/device verification.
