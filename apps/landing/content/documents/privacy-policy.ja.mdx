## 2. 顔情報と配信データの取扱い

### 2.1 取扱い主体と送信経路

InnoLiveのサービスサーバーおよびAI処理サーバーは大韓民国に設置されており、Frameworkチームが直接管理します。サーバー側の顔認識および映像の非識別化は、運営チームのAI処理サーバーで行います。登録用の顔写真および配信映像は、運営チームのサービスサーバーを経てAI処理サーバーに伝達されます。

端末で顔を検知する段階がある場合でも、登録用写真のサーバー送信とサーバー側の顔比較は別に行われます。Web体験の顔検知にはブラウザで実行するMediaPipeコンポーネントを、iOSの顔登録には端末で実行するVision機能を使用します。

映像処理の基本的な流れは次のとおりです。

```text
利用者端末のカメラ
→ Framework運営サーバー
→ Framework AI処理サーバーにおける顔検出・比較・モザイク
→ 利用者の処理映像プレビュー
→ 利用者が選択した場合のYouTube送出
```

**非識別化する前の映像が運営サーバーに送信されます。** 当該映像には、利用者および周囲の人の顔、撮影場所および背景が含まれることがあります。

YouTubeの公開配信を開始する前でも、サーバー処理プレビューまたはサーバー接続を開始すると、カメラ映像が運営サーバーに送信されます。マイクを使用するアプリでは、当該機能の同意・権限手続に従い、音声も送信します。

### 2.2 登録顔と映像内の顔の比較

顔特徴値は写真から抽出した数値情報であり、登録人物と映像内の人物が同一人物であるかを比較するために使用します。運営チームは、登録顔を会員アカウントに結び付けて管理します。

AI処理サーバーは、映像内の顔を検出・追跡し、登録顔と比較します。この過程では、登録されていない人の顔も分析することがあります。登録された人物と判断した顔はモザイクから除外し、それ以外に検出した顔にはモザイクを適用します。

顔を隠しても、音声、服装、背景および周囲の情報によって人を識別できることがあります。この機能は、映像全体の匿名性を保証しません。

### 2.3 顔情報取扱いの同意と権限

個人を識別するための顔特徴値の取扱いには、他の個人情報の取扱いと区別した機微情報の取扱い同意など、適法な根拠が必要です。会員登録の同意またはカメラへのアクセス権限のみでは、顔情報の取扱いに必要な別途の同意に代えることはできません。

他の人の顔を登録する利用者は、当該当事者に取扱い主体、項目、目的、保管・削除の基準を知らせ、必要な同意を得なければなりません。撮影者のサービス利用同意が、映像に登場する他の人の同意に代わるものではありません。運営チームも、自ら行う個人情報の取扱いに関する義務を負います。

### 2.4 学習・研究・広報目的の利用禁止

運営チームは、利用者の写真、映像、音声および顔特徴値をAIモデルの学習、研究または広報に使用しません。

当該情報は、顔登録、リアルタイム非識別化、プレビュー、中継および利用者が依頼した送出に使用します。サービス利用規約への同意のみでは、他の目的での利用権限を付与されません。

## 3. 保管および削除の基準

運営チームは、以下の基準に従い個人情報を保管し、目的を達成したとき、または保管する根拠がなくなったときは、遅滞なく破棄します。

| 情報 | 保管・削除の基準 |
| --- | --- |
| 事前申込メールおよび同意記録 | 同意の撤回、またはリリースのお知らせ・事前申込特典案内の目的達成時まで保管した後、削除します。 |
| アカウント情報 | アカウント維持中は保管し、アカウント削除処理時に当該アカウントの登録・ログイン情報を削除します。 |
| カスタマーサポートのお問い合わせ記録 | お問い合わせが解決すると、メールアドレス、お問い合わせ内容および添付資料など、お問い合わせ関連の個人情報を遅滞なく破棄します。法令上の保管義務がある情報は、当該項目および期間に限定して別に保管します。 |
| メール登録待機・認証情報 | 登録・認証を進める間、一時保存領域で取り扱い、登録完了・認証処理結果および当該一時情報の有効期間満了に従い破棄します。 |
| 認証トークン・セッション情報 | アカウント維持および認証・セッション管理に必要な範囲で保管し、アカウント削除時に関連情報を破棄します。トークンの有効期間満了・無効化と、保存された記録の削除は区別されます。 |
| 登録用顔写真の原本 | 別に持続保管しません。アップロード過程で一時ファイルが生成されることがあり、送信処理が終わると整理します。 |
| 登録顔特徴値 | AI処理サーバーのメモリに保管します。個別の顔削除、アカウント削除、または当該特徴値を保管するAIプロセスの終了・再起動時に整理されます。個別の登録リクエストや配信が終わっても、特徴値が残ることがあります。 |
| 顔登録の管理情報 | 登録顔識別子、登録項目IDおよび登録日時などを保管します。写真原本や顔特徴値は含みません。当該顔またはアカウントの削除処理時に合わせて削除します。 |
| Web体験のゲスト顔情報 | 体験セッションの終了に従い整理します。ブラウザは体験終了時にサーバーへセッション削除をリクエストします。 |
| 配信映像・音声 | ライブ処理経路には録画機能はありません。送信・処理に必要な一時メモリを使用し、処理目的を達成してそれ以上必要でなくなった映像・音声および一時追跡情報は破棄します。 |
| YouTube接続・配信情報 | 接続維持および配信管理に使用し、接続解除またはアカウント削除処理時に関連情報を破棄します。Googleで直接アクセス権限を取り消すことができ、関連情報の削除もお問い合わせ窓口へ請求できます。 |

AIプロセスを再起動すると、登録顔特徴値が消えて顔を再登録する必要がある場合があります。このとき、サーバーに残っている登録管理情報と、実際のAIメモリ上の特徴値は互いに異なる情報です。

YouTubeが保管する映像は、上表のInnoLive保管基準に含まれません。YouTubeに公開した映像は、利用者がYouTubeで別に管理する必要があります。

事前申込は、会員アカウントとは別のWebデータベースで管理します。事前申込の取消および関連情報の削除は、お問い合わせメールで別に請求できます。

法令に従い個人情報を別に保管しなければならない場合は、当該法令、保管項目および保管期間を具体的にご案内し、当該目的に限って取り扱います。

## 4. 外部サービスの利用と情報の送信

運営チームは、以下の外部サービスを使用します。各外部サービスで直接取り扱う情報には、当該提供者のポリシーが合わせて適用されます。

| 外部サービス | 利用目的 | 関連情報 |
| --- | --- | --- |
| Googleログイン | Googleアカウントによる認証 | 外部ログイン識別子、認証結果および利用者が提供に同意したアカウント情報 |
| Appleログイン | Appleアカウントによる認証 | 外部ログイン識別子、認証結果および利用者が提供に同意したアカウント情報 |
| YouTube / Google LLC | チャンネル接続、配信準備・送出および状態管理 | 接続・認証情報、チャンネル・配信識別情報、配信設定、送出した映像・音声 |
| Google STUNサーバー | Web体験のリアルタイム通信接続のためのネットワークアドレス確認 | 接続IPアドレスおよびポートなど、接続に必要な通信情報 |

Google STUNサーバーはリアルタイム通信接続を助け、jsDelivrはブラウザで実行する顔検知コンポーネントを提供します。顔登録用の写真はInnoLive運営サーバーに送信し、Google STUNサーバーまたはjsDelivrに顔写真のAI分析を依頼しません。

YouTube連携を選択した利用者の配信映像・音声は、接続したチャンネルに送信します。送信後の保管・公開・削除には、Googleのプライバシーポリシー、YouTubeポリシーおよび利用者のチャンネル設定を適用します。

YouTube接続または送信を拒否すると、当該連携・送出機能を利用できません。Google・Appleログインの利用を希望しない場合は、当該アプリで提供する他のログイン方法を選択できます。

運営チームは、ご案内した範囲を超える個人情報の第三者提供に必要な同意または法令上の根拠を確保します。

## 5. サーバー運営と外部における個人情報の取扱い

InnoLiveのサービスサーバーおよびAI処理サーバーは大韓民国にあり、Frameworkチームが直接管理します。顔登録・比較および映像の非識別化は、運営チームのAI処理サーバーで行います。

運営チームは、メール認証などサービスに必要なメールをSMTP方式で直接送信します。

Google・Appleログイン、YouTube接続・送出およびWebの外部通信には、第4項のサービスが関与します。韓国内の自主管理サーバーにおける取扱いと外部サービスにおける取扱いは区別され、外部サービスが直接取り扱う情報には、各提供者のプライバシーポリシーを合わせて適用します。

運営チームが個人情報の取扱い業務を外部に委託する場合は、受託者および委託業務を公開します。国外へ個人情報を移転する取扱いには、関連法令に従った根拠および案内・同意手続を適用します。韓国内の自主管理サーバー運営は、外部サービスを含む個人情報の国外移転がないことを意味しません。

## 6. 利用者の権利と同意の撤回

個人情報の当事者は、自己の個人情報に対する閲覧、訂正・削除、取扱いの停止または同意の撤回を請求できます。法定代理人または適法な委任を受けた代理人を通じても請求できます。

アプリで提供するアカウント・顔管理機能を利用するか、[contact@innolive.studio](mailto:contact@innolive.studio)へ請求できます。運営チームは、請求者本人または代理権限を確認するために必要な最小限の情報を確認します。

法令に従い請求を制限または拒否しなければならない場合は、その事由をご案内します。運営チームは、同意の撤回または削除の請求を受けたときは、当該取扱いの中断・削除の可否および必要な後続手続を確認します。

事前申込に同意しない場合、事前申込はできません。顔登録を拒否すると、登録人物をモザイク除外対象に指定する機能を利用できません。映像・音声のサーバー送信を拒否すると、当該サーバー処理・中継機能を利用できません。

### 児童の個人情報

InnoLiveは、登録年齢に別途の制限を設けません。満14歳未満の児童が個人情報の取扱い同意を必要とする機能を利用するには、法定代理人の同意および運営チームによる同意の確認が必要です。法定代理人は、児童の個人情報に対する閲覧、訂正・削除、取扱いの停止および同意の撤回を、お問い合わせメールで請求できます。

## 7. 顔の削除とアカウントの削除

### 登録顔の削除

アプリの**設定 > 顔管理**で登録顔を照会し、個別または全体の削除を請求できます。運営チームは、当該顔の特徴値および管理情報を削除します。

### アカウントの削除

アプリの**設定 > アカウント設定 > アカウント削除**で請求できます。運営チームは、配信セッションを終了し、外部接続の整理を試みた後、当該アカウントのアカウント・ログイン・配信接続情報および顔登録情報を削除します。

すでに外部接続権限を取り消した場合は、外部配信リソースを整理できないことがあります。この場合でも、InnoLiveが保管するアカウント情報の削除は進めます。

一時的なエラーにより顔またはアカウントの削除を完了できない場合は、アプリで再試行するか、お問い合わせメールで削除を請求できます。アプリの削除、ログアウトまたはブラウザ保存データの削除のみでは、サーバー上のアカウントや顔情報は削除されません。

**InnoLiveアカウントの削除は、YouTubeに公開した過去の映像の削除を含みません。** 事前申込の取消が必要な場合は、合わせてご請求ください。

## 8. 端末アクセス権限と端末内の保存情報

InnoLiveは、当該機能においてカメラおよびマイクのアクセス権限を使用します。現在のWeb体験はカメラのみを使用します。端末またはブラウザの権限設定でアクセス権限を変更でき、撤回した権限が必要な機能は制限されます。

端末のカメラ・マイクアクセス許可と、サーバー送信に対する同意は、互いに異なる手続です。

Webは、顔登録案内への同意の有無をブラウザのローカルストレージに保管します。利用者は、ブラウザのサイトデータ削除機能で当該情報を消去できます。

iOSアプリは、配信映像・音声送信の同意およびYouTube送信案内の確認状態を端末の設定ストレージに保管します。アカウント削除が成功すると関連状態を消去し、YouTube接続を解除するときは当該接続の案内確認状態も初期化します。

端末に保存した同意・確認状態は、サーバー上のアカウント削除や個人情報削除に代わるものではありません。

## 9. 個人情報の保護措置

アプリとサーバー間、およびサーバーとGoogle APIとの間のすべての通信は、HTTPS/TLSで暗号化します。

運営チームは、メールログインのパスワード、更新トークンおよび配信セッション所有権確認トークンをハッシュ形式で管理します。YouTube接続トークンおよび保存するApple接続トークンは、値ごとに異なるランダムなnonceを用いたAES-256-GCMで暗号化して保存し、平文では一切保管しません。短期のアクセストークンはデータベースに保存せず、リクエスト処理中のメモリ上でのみ使用します。

会員認証および配信セッションの所有権を確認してアクセスを制御し、メール認証・ログインの反復リクエストを制限します。

破棄対象の個人情報は、復元・再生が困難な方法で削除し、一時メモリおよび保存された記録は、本方針の保管・削除基準に従い整理します。

## 11. 外部ポリシーと接続権限の管理

InnoLiveはYouTube API Servicesを使用します。YouTube接続機能を利用すると、利用者にはYouTube利用規約が適用されます。

InnoLiveが要求するGoogle権限は`https://www.googleapis.com/auth/youtube`であり、利用者のYouTubeチャンネルでライブ配信を作成し、その配信状態を管理する目的にのみ使用します。YouTube Live APIには、これより狭い範囲の権限はありません。

Google APIからInnoLiveが受け取った情報の使用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに準拠します。

具体的に、InnoLiveはGoogleユーザーデータを次のとおり取り扱います。

- 利用者が要求した配信機能を提供する目的にのみ使用します。
- 広告目的で使用せず、第三者に販売しません。
- 人が直接閲覧することはありません。ただし、利用者の明示的な同意がある場合、セキュリティ目的、法令遵守のために必要な場合、またはデータが集計・匿名化されている場合を除きます。
- 機能提供に必要な期間を超えて保管せず、アカウント削除または接続解除時に保存したトークンと接続情報を整理します。
- AIモデルの学習に使用しません。

- [Googleプライバシーポリシー](https://policies.google.com/privacy?hl=ko)
- [YouTube利用規約](https://www.youtube.com/t/terms)
- [Googleアカウント接続権限の管理](https://myaccount.google.com/permissions)
- [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)
- [Appleプライバシーポリシー](https://www.apple.com/legal/privacy/)
- [jsDelivrプライバシーポリシー](https://www.jsdelivr.com/terms/privacy-policy)

利用者は、Googleアカウントの接続権限管理ページでInnoLiveのアクセス権限をいつでも取り消すことができます。権限を取り消すと、InnoLiveは該当するYouTubeチャンネルへ配信を送出できなくなり、保存した接続トークンは無効化されます。InnoLiveに残った関連情報の削除は、個人情報お問い合わせ窓口でも請求できます。
