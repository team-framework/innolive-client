# InnoLive 개인정보 처리방침

개인정보의 처리 항목, 목적과 보관·삭제 기준을 안내합니다.

- 게시일: 2026년 9월 21일
- 시행일: 2026년 9월 21일
- 서비스 운영팀: Framework 팀
- 개인정보 보호책임자: 권대형
- 개인정보 문의: [contact@innolive.studio](mailto:contact@innolive.studio)

Framework 팀(이하 “운영팀”)은 InnoLive 웹사이트, 애플리케이션 및 웹 체험 서비스에서 다음과 같이 개인정보를 처리합니다. 실제 처리 항목은 이용자가 선택한 로그인 방식과 기능에 따라 달라집니다.

현재 웹 체험 기능은 카메라 영상만 요청하며 마이크 음성을 수집하지 않습니다. 음성 처리 항목은 마이크를 사용하는 앱의 방송 기능에 적용합니다.

운영팀은 이용자가 직접 입력하거나 촬영·전송한 정보, 외부 로그인 제공자가 전달한 인증 정보, 서비스 이용 과정에서 생성한 정보를 처리합니다. 사전신청과 계정 정보 수집·이용에 대한 동의는 해당 신청·가입 화면에서 받습니다.

## 2. 얼굴정보와 방송 데이터의 처리

### 2.1 처리 주체와 전송 경로

InnoLive의 서비스 서버와 AI 처리 서버는 대한민국에 설치되어 있으며, Framework 팀이 직접 관리합니다. 서버 측 얼굴 인식과 영상 비식별화는 운영팀의 AI 처리 서버에서 수행합니다. 등록용 얼굴 사진과 방송 영상은 운영팀의 서비스 서버를 거쳐 AI 처리 서버로 전달됩니다.

기기에서 얼굴을 감지하는 단계가 있더라도, 등록용 사진의 서버 전송과 서버 측 얼굴 비교는 별도로 이루어집니다. 웹 체험의 얼굴 감지에는 브라우저에서 실행하는 MediaPipe 구성요소를, iOS 얼굴 등록에는 기기에서 실행하는 Vision 기능을 사용합니다.

영상 처리의 기본 흐름은 다음과 같습니다.

```text
이용자 기기의 카메라
→ Framework 운영 서버
→ Framework AI 처리 서버의 얼굴 탐지·비교·모자이크
→ 이용자의 처리 영상 미리보기
→ 이용자가 선택한 경우 YouTube 송출
```

**비식별화하기 전의 영상이 운영 서버로 전송됩니다.** 해당 영상에는 이용자와 주변 사람의 얼굴, 촬영 장소 및 배경이 포함될 수 있습니다.

YouTube 공개 방송을 시작하기 전에도 서버 처리 미리보기나 서버 연결을 시작하면 카메라 영상이 운영 서버로 전송됩니다. 마이크를 사용하는 앱에서는 해당 기능의 동의·권한 절차에 따라 음성도 전송합니다.

### 2.2 등록 얼굴과 영상 속 얼굴의 비교

얼굴 특징값은 사진에서 추출한 수치 정보로, 등록 인물과 영상 속 인물이 같은 사람인지 비교하는 데 사용합니다. 운영팀은 등록 얼굴을 회원 계정에 연결하여 관리합니다.

AI 처리 서버는 영상 속 얼굴을 탐지·추적하고 등록 얼굴과 비교합니다. 이 과정에서는 등록되지 않은 사람의 얼굴도 분석할 수 있습니다. 등록된 인물로 판단한 얼굴은 모자이크에서 제외하고, 그 밖에 탐지한 얼굴에는 모자이크를 적용합니다.

얼굴을 가리더라도 음성, 복장, 배경 및 주변 정보로 사람을 알아볼 수 있습니다. 이 기능은 영상 전체의 익명성을 보장하지 않습니다.

### 2.3 얼굴정보 처리의 동의와 권한

개인을 식별하기 위한 얼굴 특징값의 처리에는 다른 개인정보 처리와 구분한 민감정보 처리 동의 등 적법한 근거가 필요합니다. 회원가입 동의나 카메라 접근 권한만으로 얼굴정보 처리에 필요한 별도 동의를 대신할 수 없습니다.

다른 사람의 얼굴을 등록하는 이용자는 해당 당사자에게 처리 주체, 항목, 목적, 보관·삭제 기준을 알리고 필요한 동의를 받아야 합니다. 촬영자의 서비스 이용 동의가 영상에 등장하는 다른 사람의 동의를 대신하지는 않습니다. 운영팀도 자신이 수행하는 개인정보 처리에 관한 의무를 부담합니다.

### 2.4 학습·연구·홍보 목적의 이용 금지

운영팀은 이용자의 사진, 영상, 음성 및 얼굴 특징값을 AI 모델 학습, 연구 또는 홍보에 사용하지 않습니다.

해당 정보는 얼굴 등록, 실시간 비식별화, 미리보기, 중계 및 이용자가 요청한 송출에 사용합니다. 서비스 이용약관에 대한 동의만으로 다른 목적의 이용 권한을 부여받지 않습니다.

AI 프로세스를 재시작하면 등록 얼굴 특징값이 사라져 얼굴을 다시 등록해야 할 수 있습니다. 이때 서버에 남아 있는 등록 관리정보와 실제 AI 메모리의 특징값은 서로 다른 정보입니다.

YouTube가 보관하는 영상은 위 표의 InnoLive 보관 기준에 포함되지 않습니다. YouTube에 게시한 영상은 이용자가 YouTube에서 별도로 관리해야 합니다.

사전신청은 회원 계정과 별도의 웹 데이터베이스에서 관리합니다. 사전신청 취소와 관련 정보 삭제는 문의 이메일로 별도 요청할 수 있습니다.

법령에 따라 개인정보를 별도로 보관해야 하는 경우에는 해당 법령, 보관 항목 및 보관기간을 구체적으로 안내하고 해당 목적에 한해 처리합니다.

## 4. 외부 서비스 이용과 정보 전송

운영팀은 아래 외부 서비스를 사용합니다. 각 외부 서비스에서 직접 처리하는 정보에는 해당 제공자의 정책이 함께 적용됩니다.

| 외부 서비스 | 이용 목적 | 관련 정보 |
| --- | --- | --- |
| Google 로그인 | Google 계정을 통한 인증 | 외부 로그인 식별자, 인증 결과 및 이용자가 제공에 동의한 계정 정보 |
| Apple 로그인 | Apple 계정을 통한 인증 | 외부 로그인 식별자, 인증 결과 및 이용자가 제공에 동의한 계정 정보 |
| YouTube / Google LLC | 채널 연결, 방송 준비·송출 및 상태 관리 | 연결·인증 정보, 채널·방송 식별 정보, 방송 설정, 송출한 영상·음성 |
| Google STUN 서버 | 웹 체험의 실시간 통신 연결을 위한 네트워크 주소 확인 | 접속 IP 주소와 포트 등 연결에 필요한 통신 정보 |
| jsDelivr CDN | 웹 얼굴 감지 기능에 필요한 실행 구성요소 다운로드 | 파일 요청 과정의 IP 주소, 요청 주소, 브라우저 정보 등 통신 정보 |

Google STUN 서버는 실시간 통신 연결을 돕고, jsDelivr는 브라우저에서 실행할 얼굴 감지 구성요소를 제공합니다. 얼굴 등록용 사진은 InnoLive 운영 서버로 전송하며, Google STUN 서버나 jsDelivr에 얼굴 사진의 AI 분석을 요청하지 않습니다.

YouTube 연동을 선택한 이용자의 방송 영상·음성은 연결한 채널로 전송합니다. 전송 후 보관·공개·삭제에는 Google의 개인정보처리방침, YouTube 정책과 이용자의 채널 설정을 적용합니다.

YouTube 연결이나 전송을 거부하면 해당 연동·송출 기능을 이용할 수 없습니다. Google·Apple 로그인 이용을 원하지 않는 경우에는 해당 앱에서 제공하는 다른 로그인 방식을 선택할 수 있습니다.

운영팀은 안내한 범위를 벗어난 개인정보의 제3자 제공에 필요한 동의 또는 법령상 근거를 확보합니다.

## 5. 서버 운영과 외부 개인정보 처리

InnoLive의 서비스 서버와 AI 처리 서버는 대한민국에 있으며, Framework 팀이 직접 관리합니다. 얼굴 등록·비교와 영상 비식별화는 운영팀의 AI 처리 서버에서 수행합니다.

운영팀은 이메일 인증 등 서비스에 필요한 이메일을 SMTP 방식으로 직접 발송합니다.

Google·Apple 로그인, YouTube 연결·송출과 웹의 외부 통신에는 제4항의 서비스가 관여합니다. 국내 자체 서버에서의 처리와 외부 서비스에서의 처리는 구분되며, 외부 서비스가 직접 처리하는 정보에는 각 제공자의 개인정보처리방침을 함께 적용합니다.

운영팀이 개인정보 처리 업무를 외부에 위탁하는 경우에는 수탁자와 위탁 업무를 공개합니다. 국외로 개인정보를 이전하는 처리에는 관련 법령에 따른 근거와 안내·동의 절차를 적용합니다. 국내 자체 서버 운영이 외부 서비스를 포함한 개인정보의 국외 이전이 없음을 의미하지는 않습니다.

## 6. 이용자의 권리와 동의 철회

개인정보의 당사자는 자신의 개인정보에 대한 열람, 정정·삭제, 처리정지 또는 동의 철회를 요청할 수 있습니다. 법정대리인이나 적법한 위임을 받은 대리인을 통해서도 요청할 수 있습니다.

앱에서 제공하는 계정·얼굴 관리 기능을 이용하거나 [contact@innolive.studio](mailto:contact@innolive.studio)로 요청할 수 있습니다. 운영팀은 요청자 본인이나 대리 권한을 확인하는 데 필요한 최소한의 정보를 확인합니다.

법령에 따라 요청을 제한하거나 거절해야 하는 경우에는 그 사유를 안내합니다. 운영팀은 동의 철회나 삭제 요청을 받으면 해당 처리의 중단·삭제 여부와 필요한 후속 절차를 확인합니다.

사전신청에 동의하지 않으면 사전신청을 할 수 없습니다. 얼굴 등록을 거부하면 등록 인물을 모자이크 제외 대상으로 지정하는 기능을 이용할 수 없습니다. 영상·음성 서버 전송을 거부하면 해당 서버 처리·중계 기능을 이용할 수 없습니다.

### 아동의 개인정보

InnoLive는 가입 연령에 별도의 제한을 두지 않습니다. 만 14세 미만 아동이 개인정보 처리 동의가 필요한 기능을 이용하려면 법정대리인의 동의와 운영팀의 동의 확인이 필요합니다. 법정대리인은 아동의 개인정보에 대한 열람, 정정·삭제, 처리정지 및 동의 철회를 문의 이메일로 요청할 수 있습니다.

## 7. 얼굴 삭제와 계정 삭제

### 등록 얼굴 삭제

앱의 **설정 > 얼굴 관리**에서 등록 얼굴을 조회하고 개별 또는 전체 삭제를 요청할 수 있습니다. 운영팀은 해당 얼굴의 특징값과 관리정보를 삭제합니다.

### 계정 삭제

앱의 **설정 > 계정 설정 > 계정 삭제**에서 요청할 수 있습니다. 운영팀은 방송 세션을 종료하고 외부 연결 정리를 시도한 뒤 해당 계정의 계정·로그인·방송 연결 정보와 얼굴 등록정보를 삭제합니다.

이미 외부 연결 권한을 취소한 경우에는 외부 방송 자원을 정리하지 못할 수 있습니다. 이 경우에도 InnoLive가 보관하는 계정정보의 삭제는 진행합니다.

일시적인 오류로 얼굴 또는 계정 삭제를 완료하지 못하면 앱에서 다시 시도하거나 문의 이메일로 삭제를 요청할 수 있습니다. 앱 삭제, 로그아웃 또는 브라우저 저장 데이터 삭제만으로 서버의 계정이나 얼굴정보가 삭제되지는 않습니다.

**InnoLive 계정 삭제는 YouTube에 게시한 과거 영상의 삭제를 포함하지 않습니다.** 사전신청 취소가 필요한 경우에는 함께 요청해 주세요.

## 8. 기기 접근 권한과 기기 내 저장 정보

InnoLive는 해당 기능에서 카메라와 마이크 접근 권한을 사용합니다. 현재 웹 체험은 카메라만 사용합니다. 기기 또는 브라우저의 권한 설정에서 접근 권한을 변경할 수 있으며, 철회한 권한이 필요한 기능은 제한됩니다.

기기의 카메라·마이크 접근 허용과 서버 전송에 대한 동의는 서로 다른 절차입니다.

웹은 얼굴 등록 안내의 동의 여부를 브라우저의 로컬 저장소에 보관합니다. 이용자는 브라우저의 사이트 데이터 삭제 기능으로 해당 정보를 지울 수 있습니다.

iOS 앱은 방송 영상·음성 전송 동의와 YouTube 전송 안내 확인 상태를 기기 설정 저장소에 보관합니다. 계정 삭제 성공 시 관련 상태를 지우며, YouTube 연결을 해제할 때에는 해당 연결의 안내 확인 상태도 초기화합니다.

기기에 저장한 동의·확인 상태는 서버의 계정 삭제나 개인정보 삭제를 대신하지 않습니다.

## 9. 개인정보 보호조치

앱과 서버, 서버와 Google API 사이의 모든 통신은 HTTPS/TLS로 암호화합니다.

운영팀은 이메일 로그인 비밀번호, 갱신 토큰과 방송 세션 소유권 확인 토큰을 해시 형태로 관리합니다. YouTube 연결 토큰과 저장하는 Apple 연결 토큰은 AES-256-GCM으로 암호화해 저장하며, 값마다 서로 다른 임의의 nonce를 사용합니다. 평문은 어떤 형태로도 보관하지 않습니다. 단기 access token은 데이터베이스에 저장하지 않고 요청 처리 중 메모리에서만 사용합니다.

회원 인증과 방송 세션의 소유권을 확인하여 접근을 제어하고, 이메일 인증·로그인의 반복 요청을 제한합니다.

파기 대상 개인정보는 복구·재생하기 어려운 방법으로 삭제하며, 임시 메모리와 저장된 기록은 이 방침의 보관·삭제 기준에 따라 정리합니다.

## 11. 외부 정책과 연결 권한 관리

InnoLive는 YouTube API Services를 사용합니다. YouTube 연결 기능을 이용하면 사용자는 YouTube 이용약관의 적용을 받습니다.

InnoLive가 요청하는 Google 권한은 `https://www.googleapis.com/auth/youtube`이며, 사용자의 YouTube 채널에 라이브 방송을 생성하고 그 방송 상태를 관리하기 위한 용도로만 사용합니다. YouTube Live API는 이보다 좁은 범위의 권한을 제공하지 않습니다.

InnoLive가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy를 준수하며, 여기에는 Limited Use 요구사항이 포함됩니다.

구체적으로 InnoLive는 Google 사용자 데이터를 다음과 같이 취급합니다.

- 사용자가 요청한 방송 기능을 제공하는 목적으로만 사용합니다.
- 광고 목적으로 사용하거나 제3자에게 판매하지 않습니다.
- 사람이 직접 열람하지 않습니다. 다만 사용자의 명시적 동의가 있거나, 보안 목적, 법령 준수를 위해 필요하거나, 데이터가 집계되어 익명화된 경우는 예외입니다.
- 기능 제공에 필요한 기간을 넘겨 보관하지 않으며, 계정 삭제 또는 연결 해제 시 저장한 토큰과 연결 정보를 정리합니다.
- AI 모델의 학습에 사용하지 않습니다.

- [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)
- [YouTube 이용약관](https://www.youtube.com/t/terms)
- [Google 계정 연결 권한 관리](https://myaccount.google.com/permissions)
- [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)
- [Apple 개인정보처리방침](https://www.apple.com/legal/privacy/)
- [jsDelivr 개인정보처리방침](https://www.jsdelivr.com/terms/privacy-policy)

이용자는 Google 계정의 연결 권한 관리 페이지에서 InnoLive의 접근 권한을 언제든지 취소할 수 있습니다. 권한을 취소하면 InnoLive는 해당 YouTube 채널로 방송을 전송할 수 없으며, 저장한 연결 토큰은 무효화됩니다. InnoLive에 남은 관련 정보의 삭제는 개인정보 문의 창구로도 요청할 수 있습니다.
