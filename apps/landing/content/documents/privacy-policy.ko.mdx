# InnoLive 개인정보 처리방침

Framework 팀(이하 “운영팀”)은 InnoLive를 이용하는 사람의 개인정보를 보호하고, 어떤 정보를 왜 처리하며 언제 삭제하는지 안내합니다.

- 시행일: 2026년 10월 2일
- 서비스 운영팀: Framework 팀
- 개인정보 보호책임자: 권대형
- 개인정보 문의: [contact@innolive.studio](mailto:contact@innolive.studio)

이 방침의 시행일은 2026년 10월 2일입니다.

## 1. 적용 범위와 기본 원칙

이 방침은 InnoLive 웹사이트, 웹 체험 서비스와 iOS·Android 애플리케이션에 적용합니다. 같은 서비스라도 로그인 방식, 운영체제, 앱 버전과 선택한 기능에 따라 처리하는 정보와 처리 장소가 다릅니다. 해당 기능을 이용하지 않으면 그 기능에 필요한 정보를 요청하지 않습니다.

운영팀은 회원가입·인증, 실시간 영상 처리, 이용자가 선택한 방송 송출과 고객지원에 필요한 정보를 처리합니다. 개인정보는 서비스 제공에 필요한 적법한 근거 또는 이용자의 동의에 따라 처리하며, 민감정보 등 별도 동의가 필요한 정보는 다른 동의와 구분합니다.

**카메라 접근 허용, 얼굴 등록에 대한 동의, 서버 전송에 대한 동의와 외부 방송 플랫폼 전송에 대한 동의는 서로 다른 사항입니다.** 기기 접근 권한이나 이용약관 동의만으로 다른 처리에 필요한 동의를 대신하지 않습니다.

| 기존 사전신청 | 이메일 주소, 수집·이용 동의 시각과 방침 버전 | 이미 신청한 이용자에 대한 출시·혜택 안내, 동의 내역 확인 |

웹 체험 품질 진단은 계정·방송 식별자와 연결하지 않고 별도 DB에 저장합니다. 원본 User-Agent·IP·쿠키·토큰·영상은 이 진단 기록에 포함하지 않습니다. 서버 수신 시각 기준 30일이 지난 기록은 정기 삭제 작업으로 제거하며, 장애 시 삭제가 지연될 수 있습니다.

이름 등 외부 계정 정보는 이용자가 선택한 로그인 방식과 제공자가 전달한 범위에서 처리합니다. User-Agent에는 접속에 사용한 브라우저·운영체제 정보 등이 포함됩니다. 외부 방송 설정 항목은 선택한 플랫폼과 제공되는 기능에 따라 다릅니다.

개인정보는 이용자가 직접 입력·촬영·전송하는 과정, 외부 로그인·방송 플랫폼을 연결하는 과정, 서비스 이용 중 인증·접속·영상 처리 정보가 생성되는 과정에서 수집합니다.

현재 Web 체험은 카메라 영상만 사용하며 마이크 음성을 요청하지 않습니다. 음성 관련 항목은 마이크를 사용하는 모바일 방송 기능에 적용합니다. 기존 사전신청 정보에 대한 안내는 이미 수집한 정보의 처리에 적용하며, 현재 Web에 새로운 사전신청 기능이 있다는 의미는 아닙니다.

## 3. 영상·음성의 처리 장소와 전송 경로

### 3.1 Web 체험과 모바일 서버 AI

Web 체험과 모바일의 서버 AI 기능에서는 **비식별화하기 전의 카메라 영상이 운영 서버로 전송됩니다.** 영상에는 이용자와 주변 사람의 얼굴, 촬영 장소와 배경이 포함될 수 있습니다.

```text
기기의 카메라
→ InnoLive 운영 서버와 AI 처리 서버
→ 얼굴 탐지·비교와 모자이크
→ 처리 영상 미리보기
→ 이용자가 선택한 경우 외부 방송 플랫폼 송출
```

외부 플랫폼에 공개 방송을 시작하지 않았더라도, 서버 처리 미리보기나 방송 준비를 위한 영상 연결이 시작되면 영상이 전송됩니다. 현재 Web에서는 체험 화면에 진입하여 카메라 권한을 허용하고 연결이 시작되면 서버 처리 미리보기를 제공합니다.

Web의 브라우저 얼굴 감지는 등록할 얼굴을 확인하기 위한 단계입니다. 브라우저에서 얼굴을 감지하더라도 서버 얼굴 등록을 진행하면 등록용 사진이 운영 서버로 전송됩니다.

### 3.2 모바일 온디바이스 AI

iOS·Android에서 온디바이스 AI를 선택하면 등록 인물 비교와 영상 비식별화를 기기에서 수행합니다. 보호 기능이 켜져 정상 적용되는 동안에는 기기에서 처리한 영상이 방송 연결을 통해 전송됩니다.

```text
기기의 카메라
→ 기기 내 얼굴 탐지·비교와 모자이크
→ 처리 영상을 InnoLive 운영 서버로 전송
→ 이용자가 선택한 외부 방송 플랫폼 송출
```

**온디바이스 AI를 사용해도 방송 연결과 중계를 위한 서버 통신은 이루어집니다.** 이 모드에 등록한 얼굴 사진과 특징값은 서버 얼굴 등록정보로 자동 업로드되거나 동기화되지 않습니다. 서버 등록과 온디바이스 등록은 별도로 관리합니다.

보호 기능을 끄면 비식별화하지 않은 영상이 전송될 수 있습니다. 얼굴을 가리더라도 음성, 복장, 배경 등으로 사람을 알아볼 수 있으며, 얼굴 감지·비교의 누락이나 오류가 발생할 수 있습니다. InnoLive의 얼굴 보호 기능은 영상 전체의 익명성을 보장하지 않습니다.

### 3.3 음성과 외부 송출

마이크를 사용하는 모바일 기능에서는 권한과 필요한 동의 절차에 따라 음성을 처리하고 중계합니다. 얼굴 모자이크는 음성을 익명화하지 않습니다.

이용자가 외부 방송 플랫폼 송출을 선택하면 해당 플랫폼으로 영상·음성과 방송 정보가 전송됩니다. InnoLive의 서버 처리와 외부 플랫폼의 공개·보관은 서로 다른 처리입니다.

## 4. 얼굴정보의 처리와 목적 제한

얼굴 특징값은 얼굴 사진에서 추출한 수치 정보로, 등록한 인물과 영상 속 인물이 같은 사람인지 비교하는 데 사용합니다. 개인을 식별하기 위한 얼굴 특징값 처리에는 다른 개인정보 처리와 구분한 민감정보 처리 동의 등 적법한 근거가 필요합니다.

영상 처리 과정에서는 등록되지 않은 사람의 얼굴도 탐지·추적·비교할 수 있습니다. 등록 인물로 판단한 얼굴은 모자이크에서 제외하고, 그 밖에 탐지한 얼굴에는 모자이크를 적용합니다.

다른 사람의 얼굴을 등록하는 이용자는 당사자에게 처리 주체, 항목, 목적, 처리 장소와 보관·삭제 기준을 알리고 필요한 동의를 받아야 합니다. 촬영자의 동의가 영상에 등장하는 다른 사람의 동의를 대신하지 않습니다. 운영팀도 자신이 수행하는 개인정보 처리에 관한 의무를 부담합니다.

**운영팀은 이용자의 사진, 영상, 음성과 얼굴 특징값을 AI 모델 학습, 연구 또는 홍보에 사용하지 않습니다.** 해당 정보는 얼굴 등록·비교, 비식별화, 미리보기, 중계와 이용자가 요청한 송출에 사용합니다. 이용약관에 동의했다는 이유만으로 다른 목적의 이용 권한을 부여받지 않습니다.

## 5. 보유기간과 파기

운영팀은 개인정보를 처리 목적에 필요한 기간 동안 보관하고, 목적을 달성하거나 보관할 근거가 없어지면 지체 없이 파기합니다. 실시간 처리 중 임시로 사용하는 정보와 등록·계정 관리를 위해 보관하는 정보를 구분합니다.

| 가입 대기·이메일 인증 정보 | 가입·인증 처리 중 임시로 보관하고, 가입 완료·인증 결과와 임시정보의 유효기간에 따라 정리합니다. |

| 기존 사전신청 이메일·동의 기록 | 동의 철회 또는 출시·혜택 안내 목적 달성 시까지 보관한 후 삭제합니다. 회원 계정과 별도로 관리하므로 취소·삭제는 문의 이메일로 요청할 수 있습니다. |

브라우저가 갑자기 종료되거나 네트워크 연결이 끊기면 체험 종료·삭제 요청이 전달되지 않을 수 있습니다. 화면을 닫았다는 사실만으로 서버 정보가 즉시 삭제되었다고 볼 수 없습니다.

AI 프로세스가 재시작되면 서버 등록 특징값이 사라져 얼굴을 다시 등록해야 할 수 있습니다. 이때 서버에 남은 등록 관리정보와 AI 메모리의 특징값은 서로 다릅니다.

파기 대상 전자파일·기록은 복구·재생하기 어려운 방법으로 삭제하고 임시 메모리는 해당 처리 경로에서 정리합니다. 법령에 따라 예외적으로 보관하는 경우에는 적용 법령, 항목, 목적과 기간을 구체적으로 안내하고 해당 목적에 한해 처리합니다.

운영팀은 안내한 목적을 벗어나 개인정보를 제3자에게 제공하지 않으며, 별도 제공이 필요한 경우 동의 또는 법령상 근거를 확보합니다. 이용자가 선택한 외부 플랫폼의 공개·보관·삭제 설정은 해당 플랫폼에서 관리해야 합니다.

## 8. 처리위탁과 국외 이전

InnoLive의 서비스 서버와 AI 처리 서버는 대한민국에 설치되어 있으며 운영팀이 직접 관리합니다. 서버 얼굴 등록·비교와 서버 AI 비식별화는 이 처리 경로에서 이루어집니다. 이메일 인증 등 서비스 이메일은 운영팀이 SMTP 방식으로 직접 발송합니다.

외부 로그인, 방송 송출과 구성요소 다운로드는 제7항의 외부 서비스와 통신합니다. 국내 운영 서버를 사용한다는 사실이 외부 서비스까지 포함하여 국외 이전이 없다는 의미는 아닙니다.

개인정보 처리 업무를 외부에 위탁하는 경우에는 수탁자와 위탁 업무를 공개하고, 개인정보가 목적 외로 처리되지 않도록 필요한 계약·관리 조치를 적용합니다. 독립된 외부 서비스로의 제공과 운영팀의 업무를 대신하는 처리위탁은 구분하여 안내합니다.

국외 이전이 필요한 경우에는 관련 법령에 따른 근거와 절차를 적용합니다. 이전받는 자와 연락처, 이전 국가, 이전 항목, 시기·방법, 목적·보유기간, 이전을 거부하는 방법과 거부 시 영향을 해당 처리에 맞게 안내합니다. 별도 동의가 필요한 이전은 동의를 받은 뒤 진행합니다.

삭제 중 오류가 발생하면 다시 시도하거나 문의 이메일로 요청할 수 있습니다. 외부 권한이 이미 취소되어 방송 자원을 정리하지 못하더라도 InnoLive의 계정정보 삭제는 진행합니다.

**로그아웃, 앱 삭제와 브라우저 데이터 삭제만으로 서버 계정·얼굴정보가 삭제되지는 않습니다. InnoLive 계정 삭제는 외부 플랫폼에 이미 게시한 영상의 삭제를 포함하지 않습니다.**

얼굴 등록을 거부하면 등록 인물을 모자이크 제외 대상으로 지정할 수 없습니다. 서버 영상·음성 전송을 거부하면 해당 서버 처리·중계 기능을 이용할 수 없으며, 외부 플랫폼 전송을 거부하면 그 플랫폼의 송출 기능을 이용할 수 없습니다. 추가 기능의 이용 여부는 해당 기능에 필요한 정보 처리와 구분하여 선택할 수 있습니다.

## 10. 아동의 개인정보

InnoLive는 가입 연령에 별도의 제한을 두지 않습니다. 만 14세 미만 아동이 개인정보 처리 동의가 필요한 기능을 이용하려면 법정대리인의 동의와 운영팀의 동의 확인이 필요합니다.

법정대리인은 아동의 개인정보에 대한 열람, 정정·삭제, 처리정지와 동의 철회를 문의 이메일로 요청할 수 있습니다. 운영팀은 동의와 대리 권한 확인에 필요한 최소한의 정보를 확인합니다.

## 11. 개인정보 보호조치

운영팀은 서비스 통신에 HTTPS/TLS와 실시간 미디어 연결의 암호화를 적용하고, 회원 인증과 세션 소유권 확인을 통해 접근을 제어합니다.

서버에서는 이메일 로그인 비밀번호, 갱신 토큰과 세션 소유권 확인 토큰을 해시 형태로 관리합니다. 저장하는 YouTube·Apple 연결 토큰에는 암호화를 적용합니다. Web 인증 쿠키에는 접근 제한과 보안 속성을 적용합니다. 모바일 인증정보에는 플랫폼의 보호 저장소를 이용하며, 온디바이스 얼굴 특징값에는 iOS 파일 보호와 Android 암호화를 적용합니다.

이메일 인증·로그인의 반복 요청을 제한하고, 임시 메모리와 저장 기록은 이 방침의 보관·삭제 기준에 따라 정리합니다. 서버의 보호조치와 이용자가 기기·외부 방송 플랫폼에서 관리해야 하는 설정은 각각 적용됩니다.

## 12. YouTube API와 외부 정책

InnoLive는 YouTube API Services를 사용합니다. YouTube 연결 기능을 이용하면 YouTube 이용약관이 적용됩니다. 요청하는 Google 권한은 `https://www.googleapis.com/auth/youtube`이며, 이용자가 요청한 채널 연결과 라이브 방송 생성·송출·상태 관리에 사용합니다.

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다.

- 이용자가 요청한 방송 기능을 제공하는 목적으로 사용합니다.
- 광고 목적으로 이용하거나 제3자에게 판매하지 않습니다.
- 사람이 직접 열람하지 않습니다. 다만 이용자의 명시적 동의, 필요한 보안 대응·법령 준수 또는 해당 정책이 허용하는 집계·익명화 정보의 처리에는 예외가 적용됩니다.
- 기능 제공에 필요한 기간을 넘겨 보관하지 않으며, 계정 삭제·연결 해제 시 관련 토큰과 연결 정보를 정리합니다.
- AI 모델 학습에 사용하지 않습니다.

Google 계정의 연결 권한 관리 페이지에서 InnoLive의 접근 권한을 취소할 수 있습니다. 취소하면 해당 채널을 통한 방송 기능은 사용할 수 없으며, InnoLive에 남은 관련 정보의 삭제는 문의 이메일로 요청할 수 있습니다.
