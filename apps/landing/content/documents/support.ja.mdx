# InnoLiveカスタマーサポート

サービスの利用、エラー、アカウントおよび個人情報に関するお問い合わせを受け付けます。

**掲載日: 2026年9月19日**  
**運営チーム: Frameworkチーム**  
**お問い合わせメール: [support@innolive.studio](mailto:support@innolive.studio)**

## お問い合わせ

ログイン、顔登録、映像処理、YouTube接続・送出またはアカウント削除に問題がある場合は、メールでお問い合わせください。

確認できる範囲で、次の内容を含めてください。アカウント確認が不要なお問い合わせには、アカウント情報を送らなくても構いません。

```text
お問い合わせの種類:
問題が発生した機能:
発生日時:
端末およびオペレーティングシステム:
InnoLiveアプリバージョンまたは使用したブラウザ:
エラーメッセージおよび発生状況:
問題を再確認できる手順:
アカウントメール: アカウント確認が必要なお問い合わせにのみ記載
```

**パスワード、認証番号、認証トークンおよび配信ストリームキーは送らないでください。** 画面を添付するときは、お問い合わせと関係のない顔、メールアドレス、チャンネル情報などの個人情報を隠してください。

運営チームは、内容を確認するために追加情報が必要な場合、必要な項目をご案内します。

お問い合わせが解決すると、運営チームが保管したメールアドレス、お問い合わせ内容および添付資料など、お問い合わせ関連の個人情報を遅滞なく破棄します。法令上の保管義務がある情報は、当該法令に従った項目および期間に限定して別に保管します。

## ログインとメール認証

登録時に使用したログイン方式でアクセスしてください。アプリおよびバージョンにより、メール、GoogleまたはAppleログインを使用できます。

認証メールが見えない場合は、入力したメールアドレスおよび迷惑メールフォルダを確認してください。認証番号が期限切れの場合は、新しい認証番号を請求する必要があります。短時間にリクエストを繰り返すと、認証またはログインを一時的に制限することがあります。

問題が続く場合は、使用したログイン方式およびエラーメッセージをお知らせください。パスワードや認証番号そのものは必要ありません。

## 登録顔の照会・削除

アプリの**設定 > 顔管理**で登録顔を確認し、個別または全体の削除を請求できます。

顔登録に失敗した場合は、登録領域に一人の顔が十分大きく入っているかを確認してください。暗い照明、顔の遮蔽または大きな動きにより、検知できないことがあります。

以前に登録した顔が再びモザイクされる場合は、登録一覧を確認し、必要な顔を再登録してください。サーバーのAI処理プロセスを再起動すると、メモリに保管した特徴値が消えて再登録が必要になることがあります。

削除エラーが発生し、または登録一覧と処理結果が異なる場合は、アカウントメール、発生時刻および状況をカスタマーサポートへ送ってください。確認のために顔写真の原本を先に送る必要はありません。

## アカウントの削除

アプリの**設定 > アカウント設定 > アカウント削除**で請求できます。

アカウント削除の過程で、運営チームは配信セッションを終了し、外部接続の整理を試みた後、当該アカウントのアカウント・ログイン・配信接続情報および顔登録情報を削除します。

アプリで削除を完了できない場合は、カスタマーサポートのメールでご請求ください。請求者確認に必要な情報は別にご案内します。

アプリを端末から削除し、またはログアウトするだけでは、InnoLiveアカウントは削除されません。

### YouTube映像も合わせて削除されますか。

InnoLiveアカウントを削除しても、YouTubeに公開した既存映像は自動では削除されません。映像の削除または公開範囲の変更はYouTubeで進めてください。

外部接続権限をすでに取り消した場合は、InnoLiveが外部配信リソースを整理できないことがあります。この場合でも、InnoLiveが保管するアカウント情報の削除は進めます。

### 事前申込メールも合わせて削除されますか。

事前申込は、会員アカウントとは別に管理します。事前申込の取消およびメールの削除が必要な場合は、申し込んだメールアドレスでカスタマーサポートにご請求ください。アカウント削除のお問い合わせに、事前申込の取消請求を合わせて記しても構いません。

## YouTube接続と配信

接続したYouTubeチャンネルおよび配信権限を確認した上で、配信タイトル・説明・公開範囲および配信状態を確認してください。YouTube送信案内を確認する前には、配信準備を進めません。

InnoLiveはYouTube API Servicesを使用し、YouTube接続には`https://www.googleapis.com/auth/youtube`権限を使用します。この権限は、利用者のYouTubeチャンネルでライブ配信を作成し、配信状態を管理するために使用します。

Googleアカウントの接続権限管理ページでInnoLiveのアクセス権限を取り消すことができます。

[Googleアカウント接続権限の管理](https://myaccount.google.com/permissions)

権限を取り消すと、YouTube連携・送出機能を利用できません。InnoLiveに残っている接続情報の削除または処理状態の確認が必要な場合は、カスタマーサポートへお問い合わせください。

YouTubeのアカウント状態、配信権限またはポリシーによる制限は、YouTubeでも確認する必要があります。

関連ポリシーは、次の文書をご確認ください。

- [YouTube利用規約](https://www.youtube.com/t/terms)
- [Googleプライバシーポリシー](https://policies.google.com/privacy?hl=ja)
- [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)

## カメラ・マイクとWeb体験

端末のアプリ権限設定またはブラウザのサイト設定で、カメラ・マイクのアクセス権限を確認してください。現在のWeb体験はカメラのみを使用し、マイク音声は求めません。

Web体験を終えるときは、**体験終了**を押してください。ブラウザはカメラを停止して接続を終了し、サーバーへ体験セッションの削除をリクエストします。

ブラウザのサイトデータを消去すると、端末に保存した顔登録の同意状態が初期化されることがあります。この操作のみでは、サーバー上の会員アカウントや登録顔は削除しません。

カメラ権限を許可しても接続できない場合は、ネットワーク状態を確認し、問題が発生した端末・ブラウザおよびエラーメッセージをお知らせください。

## 処理結果が想定と異なるとき

**自分のプレビュー映像**と**サーバーで処理した映像**を区別して確認してください。カメラ原本のプレビューにはモザイクを適用しないことがあります。

隠すべき顔がサーバー処理映像または送出映像に露出した場合は、配信を中断し、カスタマーサポートへお問い合わせください。顔モザイクは、音声、服装または背景まで隠す機能を意味しません。

問題確認の資料を送るときは、他の人の顔および個人情報が不要に含まれないよう注意してください。

## 個人情報の請求と同意の撤回

個人情報保護責任者はクォン・デヒョン（권대형）であり、個人情報に関するお問い合わせは**[support@innolive.studio](mailto:support@innolive.studio)**で受け付けます。

個人情報の閲覧、訂正・削除、取扱いの停止および同意の撤回は、アプリの管理機能またはカスタマーサポートのメールで請求できます。

請求の種類および確認するアカウントまたは情報をご記入ください。請求者または代理権限の確認に必要な情報がある場合、運営チームが必要な範囲のみご案内します。

当該機能に必要な個人情報の取扱いに対する同意を撤回すると、その機能をそれ以上提供できないことがあります。

## 権利侵害・セキュリティ通報

本人の顔が同意なく登録された、または個人情報・肖像・著作権などの侵害が発生したと判断する場合は、カスタマーサポートへ通報してください。アカウントの盗用またはセキュリティ問題も、同じ窓口で受け付けます。

確認できる範囲で、発生日時、関連配信またはページのアドレス、当該場面の時間帯、問題内容および請求する措置をお知らせください。身分証明書の写し、顔写真の原本または実際の認証情報は先に送らないでください。

運営チームは、通報内容を確認し、InnoLiveが取り扱う情報およびサービス利用について必要な措置を検討します。YouTubeに公開したコンテンツに関する措置は、YouTubeの通報・削除請求手続を合わせて利用できます。
