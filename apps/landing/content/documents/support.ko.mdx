# InnoLive 고객 지원

서비스 이용, 오류, 계정 및 개인정보 관련 문의를 접수합니다.

**게시일: 2026년 9월 19일**
**운영팀: Framework 팀**  
**문의 이메일: [support@innolive.studio](mailto:support@innolive.studio)**

## 문의하기

로그인, 얼굴 등록, 영상 처리, YouTube 연결·송출 또는 계정 삭제에 문제가 있으면 이메일로 문의해 주세요.

확인할 수 있는 범위에서 다음 내용을 포함해 주세요. 계정 확인이 필요하지 않은 문의에는 계정 정보를 보내지 않아도 됩니다.

```text
문의 유형:
문제가 발생한 기능:
발생 일시:
기기 및 운영체제:
InnoLive 앱 버전 또는 사용한 브라우저:
오류 메시지와 발생 상황:
문제를 다시 확인할 수 있는 순서:
계정 이메일: 계정 확인이 필요한 문의에만 기재
```

**비밀번호, 인증번호, 인증 토큰과 방송 스트림 키는 보내지 마세요.** 화면을 첨부할 때에는 문의와 관계없는 얼굴, 이메일 주소, 채널 정보 등 개인정보를 가려 주세요.

운영팀은 내용을 확인하는 데 추가 정보가 필요한 경우 필요한 항목을 안내합니다.

문의가 해결되면 운영팀이 보관한 이메일 주소, 문의 내용과 첨부자료 등 문의 관련 개인정보를 지체 없이 파기합니다. 법령상 보관 의무가 있는 정보는 해당 법령에 따른 항목과 기간으로 제한하여 별도 보관합니다.

## 로그인과 이메일 인증

가입할 때 사용한 로그인 방식으로 접속해 주세요. 앱과 버전에 따라 이메일, Google 또는 Apple 로그인을 사용할 수 있습니다.

인증 메일이 보이지 않으면 입력한 이메일 주소와 스팸함을 확인해 주세요. 인증번호가 만료된 경우 새 인증번호를 요청해야 합니다. 짧은 시간에 요청을 반복하면 인증이나 로그인을 일시적으로 제한할 수 있습니다.

문제가 계속되면 사용한 로그인 방식과 오류 메시지를 알려 주세요. 비밀번호나 인증번호 자체는 필요하지 않습니다.

## 등록 얼굴 조회·삭제

앱의 **설정 > 얼굴 관리**에서 등록 얼굴을 확인하고 개별 또는 전체 삭제를 요청할 수 있습니다.

얼굴 등록에 실패하면 등록 영역에 한 사람의 얼굴이 충분히 크게 들어오는지 확인해 주세요. 어두운 조명, 얼굴 가림이나 큰 움직임 때문에 감지하지 못할 수 있습니다.

이전에 등록한 얼굴이 다시 모자이크되는 경우에는 등록 목록을 확인하고 필요한 얼굴을 다시 등록해 주세요. 서버의 AI 처리 프로세스를 재시작하면 메모리에 보관한 특징값이 사라져 재등록이 필요할 수 있습니다.

삭제 오류가 발생하거나 등록 목록과 처리 결과가 다르면 계정 이메일, 발생 시각과 상황을 고객지원으로 보내 주세요. 확인을 위해 얼굴 사진 원본을 먼저 보낼 필요는 없습니다.

## 계정 삭제

앱의 **설정 > 계정 설정 > 계정 삭제**에서 요청할 수 있습니다.

계정 삭제 과정에서 운영팀은 방송 세션을 종료하고 외부 연결 정리를 시도한 뒤, 해당 계정의 계정·로그인·방송 연결 정보와 얼굴 등록정보를 삭제합니다.

앱에서 삭제를 완료하지 못하면 고객지원 이메일로 요청해 주세요. 요청자 확인에 필요한 정보를 별도로 안내합니다.

앱을 기기에서 삭제하거나 로그아웃하는 것만으로 InnoLive 계정이 삭제되지는 않습니다.

### YouTube 영상도 함께 삭제되나요?

InnoLive 계정을 삭제해도 YouTube에 게시한 기존 영상은 자동으로 삭제되지 않습니다. 영상 삭제나 공개 범위 변경은 YouTube에서 진행해 주세요.

외부 연결 권한을 이미 취소한 경우에는 InnoLive가 외부 방송 자원을 정리하지 못할 수 있습니다. 이 경우에도 InnoLive가 보관하는 계정정보의 삭제는 진행합니다.

### 사전신청 이메일도 함께 삭제되나요?

사전신청은 회원 계정과 별도로 관리합니다. 사전신청 취소와 이메일 삭제가 필요하면 신청한 이메일 주소로 고객지원에 요청해 주세요. 계정 삭제 문의에 사전신청 취소 요청을 함께 적어도 됩니다.

## YouTube 연결과 방송

연결한 YouTube 채널과 방송 권한을 확인한 뒤 방송 제목·설명·공개 범위 및 방송 상태를 확인해 주세요. YouTube 전송 안내를 확인하기 전에는 방송 준비를 진행하지 않습니다.

InnoLive는 YouTube API Services를 사용하며, YouTube 연결에는 `https://www.googleapis.com/auth/youtube` 권한을 사용합니다. 이 권한은 사용자의 YouTube 채널에 라이브 방송을 생성하고 방송 상태를 관리하는 데 사용합니다.

Google 계정의 연결 권한 관리 페이지에서 InnoLive의 접근 권한을 취소할 수 있습니다.

[Google 계정 연결 권한 관리](https://myaccount.google.com/permissions)

권한을 취소하면 YouTube 연동·송출 기능을 이용할 수 없습니다. InnoLive에 남아 있는 연결정보의 삭제나 처리 상태 확인이 필요하면 고객지원으로 문의해 주세요.

YouTube의 계정 상태, 방송 권한이나 정책에 따른 제한은 YouTube에서도 확인해야 합니다.

관련 정책은 다음 문서를 참고해 주세요.

- [YouTube 이용약관](https://www.youtube.com/t/terms)
- [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)
- [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)

## 카메라·마이크와 웹 체험

기기의 앱 권한 설정이나 브라우저 사이트 설정에서 카메라·마이크 접근 권한을 확인해 주세요. 현재 웹 체험은 카메라만 사용하며 마이크 음성을 요청하지 않습니다.

웹 체험을 끝낼 때에는 **체험 종료**를 눌러 주세요. 브라우저는 카메라와 연결을 종료하고 서버에 체험 세션 삭제를 요청합니다.

브라우저의 사이트 데이터를 지우면 기기에 저장한 얼굴 등록 동의 상태가 초기화될 수 있습니다. 이 작업만으로 서버의 회원 계정이나 등록 얼굴을 삭제하지는 않습니다.

카메라 권한을 허용했는데도 연결하지 못하면 네트워크 상태를 확인하고, 문제가 발생한 기기·브라우저와 오류 메시지를 알려 주세요.

## 처리 결과가 예상과 다를 때

**내 미리보기 영상**과 **서버에서 처리한 영상**을 구분해 확인해 주세요. 카메라 원본 미리보기에는 모자이크를 적용하지 않을 수 있습니다.

가려야 할 얼굴이 서버 처리 영상이나 송출 영상에 노출되면 방송을 중단하고 고객지원으로 문의해 주세요. 얼굴 모자이크는 음성, 복장이나 배경까지 가리는 기능을 의미하지 않습니다.

문제 확인 자료를 보낼 때에는 다른 사람의 얼굴과 개인정보가 불필요하게 포함되지 않도록 주의해 주세요.

## 개인정보 요청과 동의 철회

개인정보 보호책임자는 권대형이며, 개인정보 관련 문의는 **[support@innolive.studio](mailto:support@innolive.studio)**로 접수합니다.

개인정보의 열람, 정정·삭제, 처리정지와 동의 철회는 앱의 관리 기능이나 고객지원 이메일로 요청할 수 있습니다.

요청 종류와 확인할 계정 또는 정보를 적어 주세요. 요청자나 대리 권한 확인에 필요한 정보가 있다면 운영팀이 필요한 범위만 안내합니다.

해당 기능에 필요한 개인정보의 처리에 대한 동의를 철회하면 그 기능을 더 이상 제공하지 못할 수 있습니다.

## 권리침해·보안 신고

본인의 얼굴이 동의 없이 등록되었거나 개인정보·초상·저작권 등의 침해가 발생했다고 판단하는 경우 고객지원으로 신고해 주세요. 계정 도용이나 보안 문제도 같은 창구로 접수합니다.

확인할 수 있는 범위에서 발생 일시, 관련 방송이나 페이지의 주소, 해당 장면의 시간대, 문제 내용과 요청하는 조치를 알려 주세요. 신분증 사본, 얼굴 사진 원본이나 실제 인증정보를 먼저 보내지 마세요.

운영팀은 신고 내용을 확인하고 InnoLive가 처리하는 정보와 서비스 이용에 대해 필요한 조치를 검토합니다. YouTube에 게시한 콘텐츠에 관한 조치는 YouTube의 신고·삭제 요청 절차를 함께 이용할 수 있습니다.
